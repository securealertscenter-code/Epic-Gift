# Epic Gift Stack
Telegram Mini App -> Frontend -> Express API -> PostgreSQL -> Admin Panel.

Points-only starter. No real-money, crypto, wagering, deposits, or cash-out features.

Setup:
1. Copy .env.example to .env
2. Create PostgreSQL database and run database/schema.sql
3. npm install
4. npm run dev
5. Open http://localhost:3000
6. Admin panel: http://localhost:3000/admin/
